## 项目与范围

涉及项目路径：`services/`、`apps/hexis_api.py`、`hexis-ui/app/api/chat/`、`hexis-ui/app/chat/`、`hexis-ui/lib/`、`tests/services/`、`tests/web/`、`hexis-ui/e2e/`。本计划不新增 SQL；若实际 schema 与行为事件 payload 不足，停止该项并先复核设计，不自行补迁移。

用户可见范围仅包括前台 `voice_recall`、`remember`、`add_evidence` 和 working 后台任务当轮实际执行的工具请求／结果。前台普通参数沿用文本 Chat 最多 500 字；常规结果沿用 `display_output` 最多 1000 字及真实成功／错误文案；`voice_recall` 每条正文最多 2000 字。后台 `recall` 显示实际返回正文，不使用语音 2000 字截断。普通 recall 的空值、结构异常和调用错误沿用文本逻辑。

`accepted` 不生成 Activity 项，但必须消费并推进 cursor；`done`、`failed` 显示实际权威回执；`unknown` 保留工具名称，另显示中性状态标签“结果未确认”、正文“工具调用结果无法确认。”，有真实错误原因时追加“原因：{错误原因}”。unknown 不能由 `success=false` 推断为失败。请求／结果分别有稳定事件 ID，并以真实 `call_id` 关联。

后台工具清单保持 `background_preparation.py` 当前 default registry / policy，不复制 full registry 或技能白名单，不扩容。仅投影 AgentLoop 确实发出的 `TOOL_START`／`TOOL_RESULT`；策略拒绝且未发 TOOL_START 的调用不伪造为执行事件。后台事件必须绑定任务专属 `task_session_id`，不得由 origin 会话的任务列表事件流代替。
